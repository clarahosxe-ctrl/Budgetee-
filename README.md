# Budget

Web app perso de budget (calendrier, récurrences, analyse, projection du solde), pensée pour le téléphone.
Données stockées sur l'appareil (localStorage) ; sauvegarde/restauration JSON dans **Réglages**. Fonctionne hors ligne.

## Mise en ligne (GitHub Pages)

1. GitHub → dépôt → **Settings → Pages**
2. *Source* : **Deploy from a branch**, branche choisie, dossier **/ (root)** → Save
3. Ouvre l'URL `https://<ton-compte>.github.io/Budgetee-/` sur ton téléphone
4. Chrome : menu ⋮ → **Ajouter à l'écran d'accueil** · Safari : Partager → **Sur l'écran d'accueil**

Les données sont propres à chaque appareil/navigateur : exporte une sauvegarde de temps en temps.
